In Msty Studio, attachments add files, images, webpages, and YouTube links to a conversation as extra context.

For reusable context, use [Context Studio](/studios/context-studio). Context Studio is the new name for Attachment Manager and stores attachments so they can be organized, previewed, reused, and searched with Dynamic Mode.

## Add Attachments to a Chat

Use the attachment icon in the chat input, drag items into the input area, or paste supported URLs.

You can select or unselect attached items during the conversation to control which context is included.

## Documents

Drag and drop files into the input box or use the attachment icon. Documents are saved to Context Studio and can be reused later.

## Images

Drag and drop images into the input box, use the attachment icon, or capture screenshots where supported. Images are saved to Context Studio and can also be used in [Media Studio](/studios/media-studio).

## Webpages

You can attach webpage URLs to chats by dropping them directly into the input box or by pasting URLs.

Website attachments can use Studio's default website fetch when a desktop sidecar is connected. If sidecar is unavailable, enable Jina in [Context Studio](/studios/context-studio) settings and add a Jina API key.

## YouTube Links

You can attach YouTube links to chats by dropping them directly into the input box or by pasting URLs.

As with images and documents, YouTube links can be selected or unselected as needed during the chat. Msty imports video details and transcript context when available.

## Browse Existing Attachments

Use **Browse Existing Attachments** from the attachment menu to pick items already stored in Context Studio.

This is useful when you want to reuse files, images, webpages, or YouTube links without uploading or fetching them again.

## Dynamic Mode :aurum-tag

Dynamic Mode lets a tool-capable model search selected Context Studio folders or your full context library on demand.

Use Dynamic Mode when you want the model to find relevant context itself instead of sending specific attachments with every prompt.

See [Context Studio](/studios/context-studio) for setup and requirements.
