Msty publishes a combined plain-text version of the Studio docs that AI tools can fetch and use as context.

Use this URL when an AI tool asks for a documentation URL, knowledge source, live context endpoint, custom docs source, or reference file:

```txt
https://docs.msty.ai/studio/studio-docs.txt
```

This file includes the published Msty Studio docs in one AI-friendly text file. Pointing an AI tool to this URL helps it answer questions using the latest published Studio documentation instead of relying only on the model's built-in knowledge.

## When to Use This

Use the Studio docs URL when you want an AI tool to help with:

- Setting up Msty Studio Desktop or Studio Web
- Connecting online providers or local models
- Understanding Workspaces, Knowledge Stacks, Toolbox, Agent Mode, or Settings
- Creating support replies or onboarding instructions
- Building workflows that depend on current Studio features
- Comparing Studio behavior against older Msty App documentation

## Add the Docs URL to an AI Tool

::steps

1. Copy the Studio docs URL:

   ```txt
   https://docs.msty.ai/studio/studio-docs.txt
   ```

2. Open the AI tool where you want to use Msty Studio docs.
3. Look for an option such as **Add URL**, **Add source**, **Custom docs**, **Knowledge base**, **Live context**, **Web context**, or **Reference material**.
4. Paste the Studio docs URL.
5. If the tool has a refresh, crawl, sync, or re-index option, run it so the latest published docs are loaded.
6. Ask the AI tool to answer using the Msty Studio docs source.

::

## Suggested Prompt

Use a prompt like this after adding the docs URL:

```txt
Use the Msty Studio docs at https://docs.msty.ai/studio/studio-docs.txt as your source of truth.
Answer my questions based on those docs. If the docs do not cover something, say that clearly instead of guessing.
```

For support or troubleshooting workflows, you can be more specific:

```txt
Use the Msty Studio docs source to help me troubleshoot this issue.
Give step-by-step instructions and mention which Studio feature or settings area each step applies to.
```

## Use the LLM Index

If your AI tool prefers an index of pages instead of one full text file, use:

```txt
https://docs.msty.ai/studio/llms.txt
```

The `llms.txt` file lists the main docs pages and links to the full docs text file.

## Tips

- Use the full docs text file when the AI tool can ingest large text sources.
- Use `llms.txt` when the tool expects a compact docs index.
- Refresh or re-index the source periodically if the AI tool caches external URLs.
- Do not paste license keys, API keys, or private workspace data into third-party AI tools.
- If a tool cannot fetch external URLs, download the text file and upload it manually as a document source.
