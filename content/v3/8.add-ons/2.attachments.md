title: Add attachments
description: Give a conversation documents, images, pages, or video transcripts.
---

Use the attachment control beside the message input to add context for a conversation.

## Attach content

1. Open the attachment selector.
2. Choose **Documents**, **Images**, **Webpages**, or **YouTube Links**.
3. Add the file or link, or select an existing item.
4. Wait for processing to finish, then send your question.

Use an image-capable model when you want the model to interpret an image. Webpages and YouTube links need readable page text or transcript content.

## Reuse and manage context

[Context Studio](/v3/studios/context-studio) keeps reusable attachments organized. You can select existing items without importing them again.

Where available, **Dynamic** selection follows chosen Context Studio folders or all attachments instead of a fixed list. Review that selection before sending a prompt so you know which material is included.

## Pick the right amount

Attach only the material needed for the question. Large documents can use substantial model context. For a reusable searchable collection, create a [Knowledge Stack](/v3/knowledge-stacks/overview).
