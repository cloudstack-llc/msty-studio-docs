Studios keep reusable resources separate from individual conversations.

| Studio | Use it for |
| --- | --- |
| [Persona Studio](/v3/studios/persona-studio) | Assistant instructions, user personas, and crews |
| [Prompt Studio](/v3/studios/prompt-studio) | Reusable prompts, variables, versions, and testing |
| [Skills Studio](/v3/studios/skills-studio) | Instructions that agents can use for specific tasks |
| [Context Studio](/v3/studios/context-studio) | Files, images, websites, and other reusable context |
| [Media Studio](/v3/studios/media-studio) | Image and video generation with supporting context |

Open the studio you need from the app navigation. Some resources, templates, and advanced options require Aurum; restricted actions are marked in the app.
