---
title: Query Settings
description: Control how a Knowledge Stack supplies context to the model.
---

Open a stack, choose **Query Settings**, adjust the controls, then **Save**. These settings affect retrieval; changing the embedding model belongs in **Compose Settings**.

## Choose how context is retrieved

- **Push Mode:** Msty retrieves relevant chunks and supplies them with the conversation.
- **Pull Mode:** The model can query the stack as a tool when it needs information. Use a model that supports tool calling.

Some retrieval modes and advanced controls depend on your plan.

## Tune relevance

- **Number of Chunks** controls how much retrieved material is supplied.
- **Similarity Threshold** filters out weak matches. A stricter threshold can return fewer results.
- **Semantic Search** looks for related meaning.
- **Keyword Search** matches terms; **Hybrid Search** combines keyword and semantic search where available.
- **Rerank Model** reorders retrieved chunks to improve relevance where available.

Start with the defaults. If useful sources are missing, try a more specific question or a less strict threshold before increasing the amount of context.

## Check the result

Use **Chunks Console** from the stack's menu to search its indexed content. **Chunks Visualizer** and analytics are available where your plan allows them.

If the source text is absent, update or recompose the stack rather than changing retrieval settings.
