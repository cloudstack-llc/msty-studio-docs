## Set a system prompt

1. Open **System Prompt** using the robot-face control near the composer.
2. Enter the instructions you want the model to follow, such as the role, tone, or response format.
3. Click **Apply**.

For example: “Explain unfamiliar terms and end with one practical next step.”

When prompt sync is active across multiple splits, **Apply and Share with Synced Splits** is available. Use it when those splits should follow the same instructions.

## Save instructions for reuse

1. Enter the system prompt you want to keep.
2. Choose **Save to Quick Prompts**.
3. Give it a short name and save it.

Use the Quick Prompts control in the system-prompt editor to insert a saved prompt and apply it to the chat.

## Insert a prompt while writing

Open the prompt picker from the conversation composer and select a saved prompt. It inserts into your current draft, so you can combine it with your own text before sending.

Review the resulting draft before sending, especially when a saved prompt contains placeholders or variables. Manage reusable prompts in [Prompt Studio](/v3/studios/prompt-studio).

## Choose the right scope

Use a system prompt for instructions that should guide the chat. Use a normal message for the task you want answered now. For a reusable assistant with its own model and resources, use a [persona](/v3/conversations/personas-and-crews).
