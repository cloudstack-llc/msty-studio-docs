---
title: Edit responses and explore branches
description: Revise messages, generate alternatives, and return to earlier paths.
---

## Work with a response

Move over a message to reveal its actions. Depending on the message, you can copy it, bookmark it, edit it, or open **Extra Actions**.

- **Regenerate** asks for a new assistant response as another branch.
- **Continue Generation** asks the model to continue the current answer.
- **Edit Raw Markdown** changes the saved message text directly.
- **Edit as Branch** keeps the original and saves your revision on another branch.

Editing saved text does not ask the model for a new answer. Send another prompt or regenerate when you want a model response.

## Switch between alternatives

1. Regenerate a response or edit a message as a branch.
2. Use the branch arrows beside the message to move between alternatives.
3. Open the branch count menu to label the branch or view its timeline when multiple alternatives exist.

Continuing a chat uses the path you currently selected. Keep useful alternatives instead of deleting them just to try a different answer.

## Adjust what you see and send

The **Extra Actions** menu includes controls to fold older messages, hide a message, or isolate it from model context. Hiding and context isolation are different actions: use context isolation when your aim is to exclude a message from future model requests.

**Clone with Ancestors to New Conversation** creates a separate conversation from the selected point.

## Write in Forge

Choose **New Forge Canvas** from the sidebar's new-conversation menu to work in a document editor. You can also choose **Forge Content** from a message's extra actions.

Use the editor's formatting controls or select text to ask the model to rewrite it. Available actions include simplifying, changing length, fixing spelling and grammar, and changing tone. Save changes when finished.

Forged content uses the rich text editor; raw Markdown editing is unavailable for that content. Forge availability depends on your plan.
