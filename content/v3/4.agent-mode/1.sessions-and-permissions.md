---
title: Manage agent sessions and permissions
description: Review tool requests, inspect results, and resume earlier work.
---

## Review a running task

Agent messages show progress and tool activity alongside the response. Open a tool call to inspect its input and result. When the agent provides a plan, use the plan controls to follow its steps.

Use the stop control to interrupt a task. **Disconnect** ends the current connection; when the agent is running, the header offers **Stop & Disconnect**.

## Respond to a permission request

1. Read the requested action.
2. Open **Show details** to inspect the command or other inputs.
3. Choose **Allow Once**, **Allow Always**, or **Deny**, when offered.

The available choices come from the agent. **Allow Always** grants broader approval than a single action; use the wording and scope of the current request to decide.

An operating mode can change what the agent is allowed to do. Review its description before switching modes, especially one that permits access outside the selected folder.

## Resume earlier work

1. Choose the same agent on the Agent Mode start screen.
2. Open **View session**.
3. Search or select an entry from **Recent Sessions** to resume it.

When supported, a session can also be opened in a new conversation. Session history depends on the selected agent; Msty shows a notice when it is unavailable.

## Reuse skills

Type `/` in the prompt to choose from available skills. Enabled skills from [Skills](/v3/skills) and supported skills detected for the agent can appear in the list.

Review the inserted instructions before sending. Skills guide the agent; they do not replace the agent's tool permissions or guarantee a particular result.
