Msty Studio supports models running on your computer and models hosted by a provider. Select the model for each conversation from its model selector.

## Choose a setup

| Setup | Start here |
| --- | --- |
| Use a provider API key | [Online Providers](/v3/managing-models/online-providers) |
| Connect a supported coding assistant account | [Vibe CLI Proxy](/v3/managing-models/vibe-cli-proxy) |
| Download and run a model on this computer | [Local Models](/v3/managing-models/local-models) |
| Use model files you already have | [Import Models](/v3/managing-models/import-models) |
| Connect an existing Ollama or OpenAI-compatible server | [External Model Servers](/v3/managing-models/external-servers) |

Open **Settings > Model Providers** to manage connections. Open **Settings > Local Models** to discover, download, and manage local models.

## Select a model

1. Open a conversation and select its current model.
2. Search the available models or filter by provider and purpose.
3. Choose a model for that conversation.

An image, embedding, or speech model is not automatically suitable for chat. Check its purpose when adding a custom model.

To adjust responses, see [Model Parameters](/v3/managing-models/model-parameters). To make a shortlist before connecting a model, use [Model Matchmaker](/v3/managing-models/model-matchmaker).
