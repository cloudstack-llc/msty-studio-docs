## Set up a model

1. Open Msty Studio and choose **Just exploring**, **For work**, or **I'm a developer**. This helps tailor the setup suggestions.
2. Choose a recommended local model, or connect an online provider.
3. For a local model, adjust the recommendation from **Light** to **Powerful**, then choose **Download & Get Started**. Local models need enough disk space and memory.
4. For an online provider, choose the provider, add its API key, and select at least one model before continuing. Your provider handles usage and billing.
5. Choose your first activity: chat, generate images, chat with Msty Studio Docs, or explore personas.

![The clean onboarding screen with three workflow choices](/images/v3/onboarding.png)

![The model setup step with a local recommendation and online provider choices](/images/v3/model-setup.png)

You can use **Skip to app** to explore first and add a model later under **Settings > Model Providers** or **Settings > Local Models**.

## Send your first message

1. Select **New Conversation** in the sidebar.
2. Choose your model below the message box.
3. Write a message and send it. For example: “Help me plan a small community garden.”
4. Continue the conversation, or use **Add Split Chat** to compare another model alongside it.
