Open **Settings** from the sidebar. Use the settings search to find a control by name instead of opening each section.

## App

| Section | Use it for |
| --- | --- |
| General | Language and conversation behavior. |
| Appearance | Theme, colors, and display preferences. |
| Data | Backups, restoration, storage, and recovery. |
| Environments | Named sets of workflow variables. |
| Keyboard Shortcuts | View and customize key bindings. |
| Notifications | Review, search, download, and manage app notifications. |
| Log Viewer | Search and filter application logs for troubleshooting. |

Notifications and Log Viewer are available in the desktop app. Both can export information for troubleshooting; review it before sharing.

In **Notifications**, search or filter app events, copy or download them, and remove entries you no longer need. In **Log Viewer**, search and filter logs, control automatic refresh, and copy or download the results. Clearing the log display is temporary; clearing the log file permanently deletes its entries.

## Providers and engines

| Section | Use it for |
| --- | --- |
| Model Providers | Connections to online and external model providers. |
| Local Engines | Desktop Ollama, MLX, and Llama.cpp service settings. |
| Agent Mode | Configure agent adapters and skills. |
| Vibe CLI Proxy | Connect supported coding assistant accounts through a local proxy. |
| RTD Providers | Connections used by Real-Time Data. |

See [Online Providers](/v3/managing-models/online-providers), [Agent Mode](/v3/agent-mode), and [Vibe CLI Proxy](/v3/managing-models/vibe-cli-proxy).

## Access, insights, and integrations

| Section | Use it for |
| --- | --- |
| Account | License and account access. |
| Usage | Recorded model usage. |
| Remote Tools | Desktop connector for remote tools and local models. |

The available sections depend on the platform and enabled features. For example, local-engine controls appear on desktop.

Default prompts are managed in **Prompts → Default Prompts**. MCP tools, toolsets, and Live Contexts are managed in **Toolbox**.

See [Keyboard Shortcuts](/v3/settings/keyboard-shortcuts), [Data Backups](/v3/settings/data-backups), and [Remote Tools](/v3/settings/remote-connections).
