## Open the Command Palette

Press **⌘K** on macOS or **Ctrl+K** on Windows and Linux, or use the sidebar search button.

Type the action, setting, or destination you need. Use the arrow keys to choose a result, **Enter** to run it, and **Escape** to close the palette.

The palette includes navigation, workspace switching, settings, appearance, and conversation commands. Available actions depend on the current screen.

## Change a shortcut

1. Open **Settings → Keyboard Shortcuts**.
2. Search by name or record a key combination to find its binding.
3. Choose the shortcut you want to edit and press the new combination.
4. If Msty reports a conflict, choose another combination or change the conflicting action first.

Use the category filter to narrow the list. Reset controls restore the original bindings when you want to undo customization.

Customized bindings take precedence over the default combinations shown in guides.
