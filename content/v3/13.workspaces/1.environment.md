title: Environments
description: Save named sets of variables for your workflows.
---

Environments store values used by workflows that accept environment variables. Keep a separate environment for each set of connection details you need.

## Create and activate

1. Open **Settings → Environments**.
2. Choose **New Environment** and enter a unique name.
3. Add variable names and values, then **Save**.
4. Open that environment's action menu and choose **Make Active**.

Values are hidden by default. Use **Show values** only when you need to inspect them.

## Reuse an environment

Use **Clone** to create a copy before changing a working configuration. The base environment cannot be deleted.

The New Environment menu includes **Export Environments** and a restore action. Restoring replaces existing environments, so export the current set first if you want to keep it.

Avoid putting real credentials in shared screenshots or example exports.
